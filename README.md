# Events app

Front end for the rf-json-server events API: list, add, edit and delete events, sorted by company, with a routed detail modal. React 19, JavaScript, Vite, react-router 7, axios. Every request goes to `https://rf-json-server.herokuapp.com/events`; there is no backend code in this repo.

## Run

```sh
npm install
npm run dev        # http://localhost:5173
npm test
```
